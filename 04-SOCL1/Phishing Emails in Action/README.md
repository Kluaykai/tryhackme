📚 README: Phishing Emails in Action (Real-world Tactics)
Role: SOC Analyst / Defensive Security
Objective: สรุปกลยุทธ์และการวิเคราะห์เทคนิคการอำพรางตัวของแฮกเกอร์ (Phishing Evasion & Lures)

1. 🎭 Advanced Brand Impersonation & Spoofing
แฮกเกอร์ไม่ได้ปลอมแค่ชื่อ แต่ปลอมไปถึงพฤติกรรมและการออกแบบเพื่อสร้างความตื่นตระหนก:

Display Name Manipulation: แฮกเกอร์พึ่งพาจุดอ่อนของมนุษย์ที่มักจะมองแค่ชื่อผู้ส่งโชว์ (เช่น PayPal, Netflix Billing, DHL Express) แต่ความจริงจะถูกเปิดเผยเมื่อ SOC ตรวจสอบแท็ก < > หลังชื่อ แล้วเจอโดเมนแปลกปลอม (เช่น gibberish@sultanbogor.com หรือ z99@musacombi.online)

Typosquatting ในจุดที่คาดไม่ถึง: การจงใจพิมพ์ชื่อแบรนด์ผิดแบบเนียนๆ เช่น Netllx (ใช้ตัวแอลสองตัวแทนเอฟ) เพื่อหลบเลี่ยงตัวกรองคำสั่งตรวจจับเบื้องต้น

Artificial Urgency (การสร้างสถานการณ์เร่งด่วน): การส่งใบเสร็จซื้อของที่เหยื่อไม่ได้ซื้อ (Gift Card ราคาแพง) หรือการขู่ว่าบัญชีจะถูกระงับ เพื่อบีบให้เหยื่อเกิดความกลัวและรีบดำเนินการโดยไม่ทันระวังตัว

2. 🔗 Link Manipulation & Redirection Tactics
การซ่อนและการนำทางลิงก์อันตรายเพื่อหลบหลีกระบบความปลอดภัย:

URL Shortening: การใช้บริการย่อลิงก์เพื่อปกปิดโดเมนปลายทางที่แท้จริง ทำให้ไม่สามารถตรวจสอบด้วยตาเปล่าได้ (เครื่องมือของ SOC ในการตรวจสอบอย่างปลอดภัยโดยไม่ต้องกดคลิก คือการใช้เว็บประเภท URL Redirect Checker เช่น WhereGoes)

Multi-Stage Redirection (หลอกซ้อนหลอก): การสร้างห่วงโซ่การเปลี่ยนเส้นทาง (Redirection Chain) เช่น เริ่มจากปุ่มในอีเมล -> วิ่งไปหน้า OneDrive ปลอม -> ส่งต่อไปหน้า Adobe ปลอม -> จบด้วยหน้าดักรับข้อมูล เพื่อทำ Credential Harvesting (การสร้างหน้า Portal ปลอมมาดักจับ Username และ Password ของเหยื่อส่งกลับไปหาเซิร์ฟเวอร์แฮกเกอร์)

Transparent Image Maps: เทคนิคการเขียนโค้ด HTML ครอบทับเนื้อหาเกือบทั้งหมดด้วยแท็ก <area shape="rect" coords="..."> ทำให้พื้นที่ส่วนใหญ่ในอีเมลกลายเป็นปุ่มกดลิงก์ล่องหน เหยื่อเผลอคลิกตรงไหนก็โดนนำทางไปเว็บอันตราย (เช่น devret[.]xyz) ทันที

3. 👁️ Tracking & Reconnaissance
Tracking Pixels (พิกเซลล่องหน): การแอบฝังรูปภาพขนาดเล็กมากๆ (1x1 พิกเซล) ที่มองไม่เห็นด้วยตาเปล่าไว้ใน HTML Body เมื่อเหยื่อเปิดอีเมล รูปภาพจะพยายามโหลดจากเซิร์ฟเวอร์ของแฮกเกอร์ ซึ่งเป็นการส่งสัญญาณกลับไปบอกฝั่งนั้นว่า "อีเมลฉบับนี้มีคนเปิดอ่านแล้วนะ" (นี่คือเหตุผลที่ Email Clients อย่าง Thunderbird หรือ Yahoo ต้องมีระบบ Block Remote Content เป็นค่าเริ่มต้นเพื่อปกป้องความเป็นส่วนตัว)

4. 📦 Attachment-Based Attacks (การใช้อาวุธผ่านไฟล์แนบ)
เมื่อระบบคัดกรองเนื้อหา (Email Content Filter) แข็งแกร่งขึ้น แฮกเกอร์จะหันไปพึ่งพาไฟล์แนบแทน:

Blank Body Phishing: การส่งอีเมลที่เนื้อหาว่างเปล่า 100% เพื่อไม่ให้ระบบตรวจจับ Keyword อันตรายได้ แต่จะอาศัยชื่อเรื่อง (Subject) และไฟล์แนบในการล่อลวงแทน

BCC (Blind Carbon Copy): การใช้ช่องสำเนาลับส่งหาเหยื่อพร้อมกันจำนวนมาก โดยที่เหยื่อแต่ละคนจะเห็นเหมือนว่าอีเมลนี้ถูกส่งมาหาตนเองโดยตรงเพียงคนเดียว

Suspicious Document Extensions:

.dot (Microsoft Word Template): นามสกุลไฟล์ที่ผิดปกติสำหรับใบเสร็จทั่วไป มักถูกนำมาใช้ฝังคำสั่งอันตราย (Macros) หรือลิงก์หลอกลวง

.xlsx (Excel) & Hidden Payloads: การใช้ไฟล์สเปรดชีตเป็นสะพานเชื่อม โดยเมื่อเหยื่อเปิดไฟล์และกดลิงก์ข้างใน มันจะพยายามดาวน์โหลดและรันไฟล์โปรแกรมอันตรายโดยตรงบนเครื่อง (เช่น regasms.exe) เพื่อวัตถุประสงค์ในการแอบฝังตัวในระบบ (Persistence), ขโมยข้อมูลออกไป (Data Exfiltration) หรือปล่อยไวรัสเรียกค่าไถ่ (Ransomware)
