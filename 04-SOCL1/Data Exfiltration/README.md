Data Exfiltration คือขั้นตอนที่แฮกเกอร์ "ขโมยข้อมูลความลับ" (เช่น รหัสผ่าน, ข้อมูลลูกค้า, Source Code) ส่งออกไปยังเซิร์ฟเวอร์ของตัวเอง ถือเป็นฝันร้ายที่สุดของบริษัท เพราะความเสียหายเกิดขึ้นแล้ว หน้าที่ของ Blue Team คือการสกัดกั้นหรือตามรอยให้เจอว่าข้อมูลรั่วไหลออกไปทางช่องทางไหน

แฮกเกอร์มักจะใช้ ช่องทางที่ปกติ Firewall อนุญาตให้ผ่านได้ (Covert Channels) เพื่อตบตาหลบการตรวจจับ นี่คือ 4 เทคนิคยอดฮิตและวิธีจับผิด:

1. DNS Tunneling (ขโมยผ่านการถามชื่อเว็บ)
พฤติกรรม: แฮกเกอร์เอาข้อมูลความลับมาเข้ารหัส (เช่น Base64) แล้วเอาไปแปะเป็น Subdomain ยาวๆ ส่งออกไปหาเซิร์ฟเวอร์ตัวเอง เช่น aGVsbG8xMjM=.hacker-domain.com

วิธีตรวจจับ (Detection):

ดูใน Splunk/SIEM หา DNS Query ที่มีชื่อ ยาวผิดปกติ (เช่น > 60-100 ตัวอักษร)

มีปริมาณการส่ง DNS Query ไปยังโดเมนใดโดเมนหนึ่งเยอะมากๆ ในเวลาสั้นๆ

แพ็กเก็ต DNS มีแต่คำถาม (Request) แต่ไม่มีการตอบกลับ (Response) หรือตอบกลับแปลกๆ (เช่น TXT record ขนาดใหญ่)

2. ICMP Exfiltration (ขโมยผ่านการ Ping)
พฤติกรรม: ปกติคำสั่ง Ping มีไว้เช็คว่าเครื่องปลายทางเปิดอยู่ไหม แต่แฮกเกอร์จะแอบยัดข้อมูลใส่ลงไปในส่วน Data (Payload) ของแพ็กเก็ต Ping ทำให้ข้อมูลไหลออกไปได้เนียนๆ

วิธีตรวจจับ (Detection):

ใช้ Wireshark กรอง icmp แล้วสังเกตขนาดของแพ็กเก็ต (Frame Length)

Ping ปกติจะตัวเล็ก (ประมาณ 74 Bytes) ถ้าเจอ Ping ตัวอ้วนๆ ขนาดเกิน 100 Bytes ให้สงสัยไว้ก่อนว่ามีอะไรซ่อนอยู่ข้างใน

มีการส่ง Ping รัวๆ ไปยัง IP ภายนอกที่ไม่รู้จัก

3. FTP Exfiltration (ขโมยผ่านการโยนไฟล์ตรงๆ)
พฤติกรรม: แฮกเกอร์ล็อกอินเข้า FTP (มักใช้บัญชีที่มีสิทธิ์ต่ำอย่าง Guest หรือบัญชีที่ขโมยมาได้) แล้วอัปโหลดไฟล์ความลับออกไปตรงๆ

วิธีตรวจจับ (Detection):

มีปริมาณ Data (Bytes_Sent) ขนาดใหญ่ส่งออกไปยัง IP ภายนอก

ตรวจสอบชื่อไฟล์ใน Log ถ้าเจอไฟล์แนว customer_data.csv, passwords.txt หรือไฟล์ .zip ที่ถูกเข้ารหัสส่งออกไป ต้องรีบตรวจสอบทันที

4. HTTP/HTTPS Exfiltration (ขโมยผ่านทราฟฟิกเว็บ)
พฤติกรรม: แฮกเกอร์แอบส่งข้อมูลออกไปพร้อมกับการเรียกดูหน้าเว็บปกติ โดยอาจจะซ่อนข้อมูลไว้ใน URL (GET Request) หรือซ่อนไว้ใน Body (POST Request)

วิธีตรวจจับ (Detection):

ตรวจดู HTTP Header หรือ URI ที่มีลักษณะคล้ายการเข้ารหัส (ตัวอักษรขยะๆ)

ดูปริมาณ POST Request ที่มีขนาดใหญ่ผิดปกติส่งไปยังเว็บที่ไม่น่าเชื่อถือ

🛡️ สรุปจุดโฟกัสเวลาสืบสวน (SOC Mindset)
อย่ามองหาแค่ "ไวรัส" แต่ให้มองหา "ความผิดปกติ (Anomaly)" สิ่งที่ระบบอนุญาตให้ใช้ (เช่น DNS, Ping) ไม่ได้แปลว่าปลอดภัยเสมอไป การเขียน Filter เพื่อหา "ของที่ใหญ่เกินไป" หรือ "ถี่เกินไป" คือหัวใจสำคัญในการจับ Data Exfiltration ครับ
