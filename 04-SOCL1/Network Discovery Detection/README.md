Network Discovery คือ "ก้าวแรก" ของแฮกเกอร์ (Reconnaissance) ก่อนที่จะเริ่มเจาะระบบ แฮกเกอร์จะไม่สุ่มโจมตีมั่วๆ แต่จะทำการ "สแกน" เพื่อวาดแผนที่เครือข่ายของเราให้รู้ว่ามีประตูบานไหนเปิดอยู่บ้าง หน้าที่ของ Blue Team คือต้องจับการสแกนนี้ให้ได้ก่อนที่พวกมันจะเริ่มลงมือจริง

🎯 แฮกเกอร์สแกนหาอะไรบ้าง?
ไม่ได้หาแค่ IP หรือพอร์ต แต่เป้าหมายสูงสุดคือการหา "Services" (บริการที่รันอยู่) เช่น เจอพอร์ต 80 (รู้ว่าเป็น Web Server), เจอพอร์ต 445 (รู้ว่าเป็น SMB แชร์ไฟล์) พอรู้ Service ก็จะหารูโหว่ (Vulnerability) ได้ง่ายขึ้น

🗺️ รูปแบบการสแกนที่ต้องแยกให้ออก (สำคัญมาก!)
1. รูปแบบทิศทาง (External vs Internal)

External Scan: สแกนมาจากอินเทอร์เน็ตภายนอก (ดักจับได้ที่ Firewall ขาเข้า) มักจะเป็นบอทสแกนหว่านแห หรือแฮกเกอร์ที่กำลังหาทางเจาะเข้ากำแพงเมือง

Internal Scan: สแกนจากเครื่องภายในเครือข่ายด้วยกัน (อันตรายมาก!) แปลว่าแฮกเกอร์เจาะเข้ามาได้แล้ว 1 เครื่อง และกำลังทำ Ping Sweep เพื่อหาเหยื่อเครื่องต่อไปในวง LAN เดียวกัน

2. รูปแบบพฤติกรรม (Horizontal vs Vertical) ⭐️ ออกสอบบ่อย

Horizontal Scan (สแกนแนวนอน):

พฤติกรรม: สแกน พอร์ตเดียว แต่สแกน หลายๆ เครื่อง (ทั้ง Subnet เช่น /24)

จุดประสงค์: หว่านแหหาเหยื่อ เช่น แฮกเกอร์มีเครื่องมือเจาะพอร์ต 445 ก็จะสแกนหาเฉพาะพอร์ต 445 จากทุก IP ในบริษัท เพื่อดูว่าใครลืมปิดบ้าง (คล้ายๆ เดินบิดลูกบิดประตูทุกบานในตึก)

Vertical Scan (สแกนแนวตั้ง):

พฤติกรรม: สแกน หลายๆ พอร์ต แต่เล็งเป้าแค่ เครื่องเดียว (IP เดียว)

จุดประสงค์: ล็อกเป้าหมายแล้ว! อยากรู้ว่าเซิร์ฟเวอร์เครื่องนี้รันบริการอะไรบ้างตั้งแต่พอร์ต 1 ยัน 65535 เพื่อหาช่องทางที่เจาะได้ง่ายที่สุด

⚙️ เทคนิคการสแกนยอดฮิต (The Mechanics)
Ping Sweep (ICMP): ส่งเสียงเรียก (Ping) ไปหาทุก IP ในวง LAN เพื่อดูว่าเครื่องไหนเปิดอยู่บ้าง (เครื่องไหนตอบกลับมา แปลว่ามีชีวิต)

TCP SYN Scan (Stealth Scan): เป็นท่ามาตรฐานของ Nmap (ส่งแพ็กเก็ต SYN ไปถาม ถ้าเซิร์ฟเวอร์ตอบ SYN-ACK แฮกเกอร์จะชิ่งหนีไม่คุยต่อ เพื่อไม่ให้ระบบบันทึก Log การเชื่อมต่อแบบเต็มรูปแบบ)

UDP Scan: สแกนหาบริการที่ใช้ UDP (เช่น DNS, SNMP) ซึ่งสแกนยากและช้ากว่า TCP มาก

🕵️‍♂️ วิธีตรวจจับ (Detection)
Log ปริมาณมหาศาล: ถ้าเห็น IP เดียวสร้าง Connection หรือ Error Log (เช่น Connection Refused) เป็นพันๆ รายการในเวลาไม่กี่วินาที (อย่างในแล็บที่เจอ 2276 logs) ฟันธงได้เลยว่ากำลังโดนสแกน

Zeek Logs: ถ้าใช้ Zeek (Network Monitoring Tool) ให้ดูที่ช่อง conn_state ถ้าเห็นสถานะแปลกๆ ที่เชื่อมต่อไม่สมบูรณ์เยอะๆ นั่นแหละคือร่องรอยการทำ SYN Scan
