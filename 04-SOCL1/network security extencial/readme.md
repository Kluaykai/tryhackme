🛡️ อุปกรณ์หน้าด่านและวิธีอ่าน Log (Key Data Sources)
1. Firewall Logs (บันทึกการเข้าออกของประตูเมือง)

หน้าที่: ตรวจสอบว่า IP ไหน/Port ไหน ได้รับอนุญาตให้ผ่าน (Allow) หรือถูกบล็อก (Drop/Deny)

พฤติกรรมต้องสงสัยที่ต้องมองหา:

Port Scanning: IP เดียวพยายามเชื่อมต่อเข้ามาหลายๆ Port ในเวลาสั้นๆ (เช่น 203.0.113.10 สแกนหาช่องโหว่)

Lateral Movement: การพยายามเชื่อมต่อที่ผิดปกติจากเครื่องภายในสู่เครื่องภายในด้วยกัน (เช่น การพยายามใช้ Port 445 SMB เพื่อแพร่กระจายมัลแวร์)

2. WAF Logs - Web Application Firewall (ยามเฝ้าหน้าเว็บ)

หน้าที่: ตรวจจับและบล็อกการโจมตีที่พุ่งเป้ามาที่เว็บไซต์ (HTTP/HTTPS) โดยเฉพาะ

พฤติกรรมต้องสงสัยที่ต้องมองหา:

IP ที่พยายามยิง Payload แปลกๆ เข้ามาซ้ำๆ เช่น SQL Injection (' OR 1=1), XSS หรือ Directory Traversal (../../../etc/passwd)

3. VPN Logs (บันทึกการลักลอบเข้าเมืองผ่านอุโมงค์)

หน้าที่: บันทึกการเข้าสู่ระบบเครือข่ายจากระยะไกล

พฤติกรรมต้องสงสัยที่ต้องมองหา:

Brute-Force Attack: มีการ Login ล้มเหลวซ้ำๆ ถี่ๆ (เช่น 90 ครั้งในไม่กี่นาที) จาก IP เดียว

Compromised Account: แฮกเกอร์เดารหัสผ่านสำเร็จ และได้รับแจก IP ภายใน (Assigned Internal IP) เพื่อเข้ามาป่วนในระบบต่อ

4. IDS Logs - Intrusion Detection System (ระบบสัญญาณกันขโมย)

หน้าที่: ตรวจจับรูปแบบแพ็กเก็ตที่ตรงกับลายเซ็น (Signature) ของมัลแวร์หรือพฤติกรรมอันตราย

พฤติกรรมต้องสงสัยที่ต้องมองหา:

C2 Beaconing: เครื่องในองค์กรแอบส่งสัญญาณไปหาเซิร์ฟเวอร์ควบคุมของแฮกเกอร์ (Command & Control)

Data Exfiltration: มีการแอบส่งข้อมูลขนาดใหญ่ออกไปยัง IP ภายนอกที่ไม่รู้จัก

🕵️‍♂️ สรุป Workflow การสืบสวน (Incident Investigation)
เวลาเกิดเหตุการณ์ (Breach) แฮกเกอร์มักจะทิ้งร่องรอยไว้ตามลำดับนี้ (อิงจากแล็บที่คุณเพิ่งทำไปเลยครับ):

Reconnaissance: แฮกเกอร์เริ่มสแกนกำแพงเมือง (ดูจาก Firewall Logs)

Initial Access: แฮกเกอร์พยายามเจาะเข้าเมือง เช่น ทุบประตูรหัสผ่าน VPN (ดูจาก VPN Logs)

Lateral Movement: พอเข้ามาได้ ก็เริ่มลามไปเครื่องอื่นในองค์กรผ่าน Port ยอดฮิตอย่าง 445 (ดูจาก Firewall Logs ฝั่ง Internal)

C2 & Exfiltration: ฝังมัลแวร์ โทรกลับฐานทัพ แล้วขโมยข้อมูลออกไป (ดูจาก IDS Logs)
