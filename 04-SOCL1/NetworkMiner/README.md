📝 README: NetworkMiner (Quick Reference Guide)
NetworkMiner คือเครื่องมือวิเคราะห์หลักฐานทางเครือข่าย (Network Forensics Analysis Tool - NFAT) แบบ Passive หน้าที่หลักคือการเอาไฟล์ดักจับทราฟฟิก (PCAP) มาแกะกล่อง ย่อยข้อมูล และจัดหมวดหมู่ให้คนอ่านเข้าใจง่ายที่สุด เหมาะมากสำหรับการกวาดหา "หลักฐานชิ้นใหญ่" (Low-hanging fruit) อย่างรวดเร็ว

🛠️ หน้าต่างการใช้งานหลัก (Core Tabs)
Hosts:

สรุปรายชื่อเครื่องทั้งหมดที่คุยกันในเครือข่าย

ทำ OS Fingerprinting ทายระบบปฏิบัติการ (Windows, Linux ฯลฯ) จากทราฟฟิก

บอก IP, MAC Address, พอร์ตที่เปิด และสถิติการรับ-ส่งแพ็กเก็ต

Files & Images:

ไม้ตายของโปรแกรม! สกัดไฟล์ (HTML, เอกสาร, มัลแวร์) และรูปภาพที่วิ่งอยู่ในเครือข่ายออกมาเป็นไฟล์ให้ดับเบิลคลิกดูได้เลย

Credentials:

ดักจับ Username / Password ที่ส่งมาแบบไม่ได้เข้ารหัส (Cleartext)

สกัดค่า Password Hash (เช่น NTLM) ออกมาให้ก๊อปปี้ไปแคร็กต่อใน Hashcat หรือ John the Ripper

Messages:

ประกอบร่างแพ็กเก็ตกลับมาเป็นหน้าตาของอีเมล หรือข้อความแชท (แสดงผู้ส่ง ผู้รับ และหัวข้อชัดเจน)

Anomalies:

ตรวจจับความผิดปกติเบื้องต้น (เช่น พฤติกรรม Spoofing หรือช่องโหว่อย่าง EternalBlue)

⚠️ ข้อจำกัดที่ต้องรู้ (Cons)
ห้ามใช้ดักข้อมูลสด (Active Sniffing): แม้จะมีฟีเจอร์นี้ให้ใช้บน Windows แต่มันไม่เสถียร แนะนำให้ดักไฟล์ด้วย tcpdump หรือ Wireshark แล้วค่อยเอาไฟล์มาโยนใส่จะดีกว่า

กินสเปคกับไฟล์ใหญ่: ถ้าไฟล์ PCAP ใหญ่มากๆ โปรแกรมอาจจะค้าง หรือโหลดข้อมูลมาแสดงผลไม่ครบ (วิธีแก้คือต้องกด Clear แล้วโยนไฟล์โหลดใหม่)

ไม่มีระบบ Filter ที่ซับซ้อน: ค้นหาคำได้เบื้องต้น แต่เขียนสคริปต์กรองแบบลึกๆ ไม่ได้

🔄 ความต่างของเวอร์ชัน (Version Differences)
เวอร์ชันเก่า (v1.6):

มีแท็บ Frames ให้นับจำนวนเฟรมได้

ดูรายละเอียดของ Packet / Cleartext ได้ลึกกว่า

เวอร์ชันใหม่ (v2.x ขึ้นไป):

ตัดแท็บ Frames ทิ้ง เพื่อประหยัด RAM เครื่องเวลาประมวลผล

เพิ่มระบบจัดการ Parameter ที่ดีขึ้น

สามารถจัดกลุ่มตรวจจับ MAC Address ซ้ำซ้อน ได้

💡 Best Practice (Workflow การทำงาน)
เวลาเจอเหตุการณ์ต้องสงสัย (Incident) ให้โยนไฟล์ PCAP เข้า NetworkMiner เป็นอันดับแรก เพื่อสโคปภาพรวมว่า "ใคร, ทำอะไร, มีไฟล์/รหัสผ่านอะไรหลุดบ้าง"

จากนั้น หากต้องการเจาะลึกดูความผิดปกติในระดับโปรโตคอล หรือเจาะดูข้อมูลดิบทีละบรรทัด ให้สลับไปเปิดไฟล์เดิมใน Wireshark เพื่อวิเคราะห์ขั้นสูงครับ
